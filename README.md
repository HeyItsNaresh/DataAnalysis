How to run the Toolkit

PRE-REQUISITE : Python should be installed on your system

STEP 1- Unzip the ZN-Analytics-Toolkit file.
STEP 2- Open the terminal INSIDE the unzipped folder.
STEP 3- Run the command "pip install -r requirements.txt".
STEP 4- Once all the downloads are finished, run the command "python -m streamlit run app.py".
STEP 5- Explore the toolkit, enjoy
